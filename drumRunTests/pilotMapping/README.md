# Legacy five-drum mapping pilot

This is the earlier two-IMU, five-target mapping experiment. It collected 100
hits per target per hand, but held-out-round accuracy was only 36.4% for the
left hand and 25.8% for the right hand. Retain it for comparison and research
traceability; do not use its trained map as the current live classifier.

The next pilot uses only kick, snare, and crash with revised session calibration
and feature validation.
