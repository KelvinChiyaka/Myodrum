# IMU diagnostics

`mainIMUDiagnostics.m` preserves the former `IMU_subsystem/mainIMU.m`
calibration-and-plot workflow for deliberate diagnostic work.

It is not the normal playing entry point. Run `mainMyoDrum("dual-kick")` or
the compatibility function `mainIMU` to load cached calibration and continue
automatically into two-hand kick playback.
